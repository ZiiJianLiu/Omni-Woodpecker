# Sample requests

`owp_input.jsonl` contains three representative CMM requests covering
visual-only, audio-only, and audio-video input. `owp_expected_output.jsonl`
shows the public output schema. The media paths follow the CMM annotation
index; on a source-only checkout, OWP resolves the corresponding media into
the user cache automatically on first use. The expected file is a contract
fixture, not a fixed model-regression target.
