# Bundled CMM sample media

These four small files are the media referenced by the three requests in
`../owp_input.jsonl`:

| Request | Bundled files | Input coverage |
|---|---|---|
| `cmm:00000` | `cmm_00000_video.mp4` | visual-only |
| `cmm:00400` | `cmm_00400_audio.wav` | audio-only |
| `cmm:01200` | `cmm_01200_video.mp4`, `cmm_01200_audio.wav` | audio-video |

The files are representative media copied from the corresponding CMM release
items. They are included only to make the integration examples self-contained;
the CMM dataset citation and usage terms in `data/CMM/README.md` and
`docs/ASSET_NOTICES.md` apply.
